# Курсовая работа "Телефонный справочник"

##  Краткое описание

Консольное приложение для работы с бинарным файлом абонентов с асинхронной загрузкой, фильтрацией по префиксу номера, редактированием данных
и безопасным сохранением.

##  Функционал

- Асинхронное чтение большого бинарного файла
- Фильтрация по первым 4 цифрам номера (результат в `filtered.txt`)
- Добавление, изменение (не-ключевые поля) и удаление абонентов
- Конфликт-лог `error.txt` при попытке добавить существующий номер
- Безопасная перезапись через временный файл
- Потокобезопасность (`lock`) для коллекций
- Использование комбинации коллекций SortedSet + Dictionary, как оптимальный способ хранения данных для этой задачи
